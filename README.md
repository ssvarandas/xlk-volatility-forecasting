# xlk-volatility-forecasting

# Beyond Implied Volatility: Investor Sentiment and Conditional Variance in US Technology Equities

This repository contains the full codebase for my thesis submitted to IE University, 2026.
The project investigates whether incorporating investor sentiment as an exogenous variable
into a GJR-GARCH-X framework improves conditional variance forecasting for XLK,
the US Technology Select Sector SPDR ETF.

## Abstract

Five GJR-GARCH-X specifications are estimated, with the key contribution being an
orthogonalized sentiment measure that isolates the Fear & Greed Index's component
independent of the VIX, directly addressing the structural overlap between the two signals.
Implied volatility improves how well the model fits historical data, but none of the
indicators pose meaningful improvement in out-of-sample forecast accuracy; the joint
specification combining both measures yields marginal gains that fall short of statistical
significance. This suggests that for the methodology employed, sentiment indices, however
informationally rich, do not extend forecasting value beyond implied volatility in high-beta
sector settings, raising questions about their practical utility in short-term variance
forecasting.

## Workflow

This project uses both Python and R. Python must be run first — it generates
the CSV files that the R modelling scripts consume.

### Step 1 — Python (Data Collection & Preprocessing)

Install dependencies:
pip install numpy pandas matplotlib seaborn scipy scikit-learn arch

Run the main Python script:
python src/main.py

This generates the cleaned and processed CSV files in the data/ folder.

### Step 2 — R (GJR-GARCH-X Modelling)

Open RStudio and install required packages:
install.packages(c("rugarch", "moments", "FinTS", "car"))

Run the R scripts in order after Step 1 has completed.

## Data Sources

- XLK price data: Yahoo Finance
- Implied volatility: CBOE VIX Index (Federal Reserve Economic Data, FRED)
- Sentiment indicator: CNN Fear & Greed Index
  Historical data obtained from: https://github.com/whit3rabbit/fear-greed-data
